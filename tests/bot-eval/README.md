# اختبار هلوسة بوت واتساب (Promptfoo)

25 حالة من أصعب ما ظهر في `bot_reply_audit`، تُرسل لـ **نسخة اختبار معزولة** من مسار واتساب في n8n
(«اختبار البوت — نسخة معزولة (واتساب)»): نفس العُقد والموجّه والأدوات، بلا إرسال واتساب ولا إنشاء شحنات،
وتقبل أرقام الاختبار فقط (`964770999xxxx`).

| الملف | الدور |
|---|---|
| `cases.json` | الحالات: الرسائل (دور أو دورين) والفحوص المطلوبة لكل حالة |
| `assertions.mjs` | الفحوص الثابتة (بلا نموذج حَكَم): كل فشل موسوم `[هلوسة]` أو `[سلوك]` |
| `provider.mjs` | مزوّد Promptfoo: يعيد الردود المسجّلة، أو يرسل للـ Webhook إذا `BOT_EVAL_URL` معرّف |
| `build_outputs.py` | يبني `results/outputs.json` من ملفات تنفيذ n8n المحفوظة |
| `collect_executions.py` | الزمن والتوكنز والتكلفة لكل تنفيذ |

## التشغيل

```bash
npx promptfoo@latest eval -c tests/bot-eval/promptfooconfig.yaml
```

```bash
npx promptfoo@latest view
```

للتشغيل الحي على البوت بدل الردود المسجّلة: انشر نسخة الاختبار، وعرّف `BOT_EVAL_URL` برابط الـ Webhook الإنتاجي لها.
